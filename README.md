# Dreaming Precise Time

Chrome extension that displays precise time (hours and minutes) on Dreaming Spanish/French progress pages.

## Features

- Shows exact hours and minutes instead of rounded hours
- Works with both languages

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" in the top right
3. Click "Load unpacked"
4. Select the `src` folder

## Usage

Visit your progress page:
- https://app.dreaming.com/french/progress
- https://app.dreaming.com/spanish/progress

The extension will automatically replace the rounded time display with precise hours and minutes.
